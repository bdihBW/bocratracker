Everything needed to build the database: 12 migrations, seed data and 3 Edge Functions. Built 2026-11-01 21:20 UTC.

Install

  1. Create the database project (development first, then staging and production).
  2. Run the compressed script in the SQL editor, or run the migrations in order with supabase db push and then the seed.
  3. Deploy the Edge Functions and set the secret TURNSTILE_SECRET. Allowed web addresses are kept in settings.app_origins.
  4. Work through the items marked "Configure" in the checklist below.
